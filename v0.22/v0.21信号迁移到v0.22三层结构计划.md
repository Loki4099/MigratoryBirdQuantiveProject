## 1. 为什么必须分两步

一次同时改变运行架构和信号数学逻辑，会导致结果变化无法归因。因此每个 v0.21 Signal Version 必须依次经历：

### 阶段 A：Parity Mapping / 等价迁移

- 原公式、参数、方向、频率、缺失规则和 Known At 不变；
- 映射到 Raw Input、三个加工层、透传和 Aggregation 接口；
- 新旧输出在相同 Data Bundle、Asset Context 和日期范围内逐值比较；
- 只有达到冻结的数值容差、行数、缺失位置和排序一致性后，才标记兼容迁移完成；
- v0.21 Artifact 保持原样，新结果发布为 v0.22 兼容 Artifact。

### 阶段 B：Native Redesign / 原生重构

- 重新研究该信号应如何拆分为有经济意义的中间产物；
- 可以引入更合理的三层结构、Pattern、新闻、向量或模型；
- 任何公式、窗口、时间语义或输出含义变化，都发布新的 Node/Signal Version；
- 新版本与等价迁移版本并行诊断，不覆盖旧版本。

## 3. 固定拓扑

```text
Raw Input Source
      ↓
Processing Stage 1
      ↓
Processing Stage 2
      ↓
Processing Stage 3
      ↓
用户在 Stage 3 选择聚合输入
      ↓
Aggregation Instance
```

- Raw Input 不占用三个加工层；
- 任一层输出可以零拷贝透传到下一层；
- 等价迁移不要求每条旧信号都进行三次真实计算；
- 没有真实加工时使用 Layer Projection，不增加假节点；
- 聚合器只读取 Stage 3 明确选择的信号。

## 4. 建议迁移批次

### Batch 0：契约验证样例

1. `return_continuation`：连续标量、简单方向变换；

## 6. 等价验收标准

每个具体 Signal Version 至少验证：

- 相同资产集合、数据版本、日历和频率；
- 输出主键集合完全一致；
- 缺失位置及缺失原因一致；
- 状态和事件日期一致；
- Decimal/浮点输出达到预先冻结的容差；
- 横截面排序和边界并列处理一致；
- Semantic Fingerprint 对新图稳定，点击顺序不影响结果；
- 正向选择和反向点亮编译成相同图；
- 每层可导出，透传不复制 Payload；
- 新血缘可以回到原始 Data Bundle、Node Version、Engine 和兼容源 Artifact。

## 7. 完成定义

只有满足以下条件，才能宣布“全部 v0.21 信号已迁移”：

1. 51 个具体 Signal Version 全部进入迁移台账；
2. 每个版本均存在可运行的 v0.22 兼容图；
3. 每个版本均通过等价验收或明确记录无法迁移原因；
4. 所有现有聚合模型至少完成一次完整兼容映射；
5. 固定的 v0.21 回归 Experiment 能由 v0.22 图重跑并通过差异门禁；
6. 历史 v0.21 Artifact 未被覆盖或重写；
7. 原生重构版本与兼容版本使用不同身份，不混淆研究结论。
