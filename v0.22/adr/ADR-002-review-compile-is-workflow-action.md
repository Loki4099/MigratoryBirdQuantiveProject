# ADR-002：检查与编译是策略工作流动作，不是加工层

> 状态：accepted
>
> 确认时间：2026-08-12
>
> 决策来源：用户在主导航验收中指出独立“检查并编译”看起来像新增的数据加工层
>
> 取代范围：ADR-001 的主导航独立 Review、Strategy/Review 分页和相应实现清单；其余条款继续有效

## 决策

1. v0.22 主导航不再显示独立“检查并编译”。
2. 配置检查、资源准入和精确研究图编译保留，但嵌入“策略”页面底部。
3. 该区域明确标注为提交前工作流动作：没有 `stage_no`，不生产信号，不改变三加工层与唯一聚合层结构，也不直接启动实验。
4. 历史 `/research-review` 与 `/workspace-v022/review` 路由保留为兼容别名，分别重定向到策略页的配置检查锚点。
5. 编译继续显式触发；系统不得因策略选择变化而自动编译，避免把未完成或不合法草稿固化为研究图。

## 验收条件

- 侧栏只呈现资产、加工层 1/2/3、聚合层、策略、实验与产品等产品概念；
- 策略页同时显示策略/防御选择和“配置检查与编译”区域；
- 原 Review 深链接不产生第二份 Draft，也不形成新导航层；
- 编译前仍展示最终信号、聚合器、策略/防御、预计分支、资源准入和 blockers；
- 编译按钮只生成不可变研究图，不宣称已启动实验。
