# 阶段 7：批量入口、只读 API 与研究界面实施报告

完成日期：2026-08-01
状态：已完成

## 1. 交付结果

- 增加 `style-rotation-pipeline-update`，顺序执行数据、因子、信号、回测和指标五层任务；任一层失败即停止。
- 增加本地 `style-rotation-web` 服务，默认仅监听 `127.0.0.1:8000`。
- 增加只读 API：健康检查、正式结果状态、筛选选项、排行榜、因子详情及最多四组回测对比。
- 增加首页排行榜、因子详情页和回测对比页；页面同时展示收益、风险、IC、收益差、换手、成本及储备权重，不以单一指标定义“最佳因子”。
- 回测对比页展示策略净值和 SPY 买入持有净值；长序列只在展示层确定性降采样，正式指标不重新计算。

## 2. 数据与安全边界

- 前端只读取最新且包含完整 288 个发布结果的正式指标版本。
- 数据库查询事务显式设置为只读；本阶段未增加数据库表、迁移或结果副本。
- 页面不会启动回测、修改配置、选择参数或写入数据库。
- 系统仍为本地个人研究工具；公共部署、登录权限和远程任务调度属于未来版本。

## 3. 页面与接口

- `/`：正式结果完整性、筛选条件、综合指标排行榜和回测勾选。
- `/factors/{factor_variant_id}`：公式、参数、方向、周/月诊断时间序列和 12 种策略配置。
- `/compare?run_ids=...`：最多四组正式回测的指标表、策略净值和 SPY 基准。
- `/docs`：FastAPI 自动生成的本地 API 文档。

## 4. 运行方式

```powershell
style-rotation-web
```

完整更新：

```powershell
style-rotation-pipeline-update --start 1999-01-01 --end 2026-07-30
```

## 5. 验收口径

- Ruff、mypy strict 通过。
- 轻量 API/页面路由测试通过。
- 正式 PostgreSQL 可用时，状态接口必须确认 288 个发布、48 个诊断集、38,448 个诊断期间和 14,688 条指标明细；任一计数异常时页面显示 `attention`，而非静默当作完整结果。
