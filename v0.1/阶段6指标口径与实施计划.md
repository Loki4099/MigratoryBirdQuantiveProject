# 阶段 6：指标口径与实施计划

状态：已完成并通过正式批次验收  
冻结日期：2026-07-31  
适用范围：v0.1 正式 24 因子、周/月频、两套模板、2/5/10 bps 成本场景

## 1. 边界

指标层只读取已发布的信号、清洗价格、DGS3MO、每日净值、每日持仓和基准结果。
不得在指标层重新生成信号、仓位、成交、成本或净值。

Rank IC 与 Top 2-Bottom 2 只依赖因子、频率和上游版本，因此全矩阵共享
24 × 2 = 48 个诊断集；运行级收益风险指标按 288 个 `run_id` 分别发布。

## 2. 统一绩效口径

- 使用每日简单收益，不使用对数收益。
- gross 和 net 分别计算；gross 只与 gross 基准比较，net 只与同成本 net 基准比较。
- 波动率、Tracking Error 和比率使用 252 个交易日年度化；样本标准差采用 `ddof=1`。
- CAGR 使用实际日历年：`T = (official_end_date - first_execution_date) / 365.2425`，
  `CAGR = ending_nav ** (1 / T) - 1`。
- 年化单边换手为 `sum(daily_turnover) / T`，包含初始建仓，不添加期末清仓。
- 所有不可定义值写入 `NULL + stable reason_code + observation_count`，禁止 NaN 或无穷值。

## 3. 因子诊断

### 3.1 Rank IC

每个完整预测期使用全部四只 ETF：

`forward_return = next_execution_open_adj / current_execution_open_adj - 1`

`Rank IC = Spearman(oriented_factor_value, forward_return)`

- 不应用 SMA200 过滤，也不使用储备仓位。
- Spearman 数值并列采用统计学平均秩；不能使用交易选择的 ticker 强制破并列秩。
- 因子截面或远期收益截面为常数时，该期 IC 为空并保存原因。
- 最后一个没有下一执行日的事件不进入诊断期。
- `mean_rank_ic` 为有效 IC 算术均值。
- `positive_ic_ratio = count(IC > 0) / valid_ic_count`；零 IC 不算正 IC。

### 3.2 Top 2-Bottom 2

每期按统一方向值排序，边界并列沿用冻结顺序 `IWF → IWD → IWO → IWN`：

`spread = mean(return_rank_1_2) - mean(return_rank_3_4)`

该指标成本前、不含储备、不应用趋势过滤。汇总值为各原生周/月持有期 spread 的算术均值，
不年度化；周频和月频值必须连同频率展示。

## 4. 收益、风险与相对指标

- 累计收益：`ending_nav - 1`。
- 年化波动率：`sample_std(daily_return) * sqrt(252)`。
- 最大回撤：`min(nav / running_peak - 1)`，峰值序列必须包含初始财富 1；结果保存为非正数。
- Sharpe：`mean(daily_return - risk_free) / sample_std(excess) * sqrt(252)`。
- Sortino：分母为 `sqrt(mean(min(excess, 0) ** 2))`，再乘 `sqrt(252)`。
- Calmar：`CAGR / abs(max_drawdown)`。
- 累计相对收益：`strategy_ending_nav / B1_ending_nav - 1`。
- Tracking Error：`sample_std(strategy_daily_return - B1_daily_return) * sqrt(252)`。
- Information Ratio：`mean(active_daily_return) / sample_std(active_daily_return) * sqrt(252)`。

B1 为相同频率、相同成本的四 ETF 等权基准。SPY 单独计算并展示自身指标，不作为默认
Tracking Error 或 Information Ratio 基准。

## 5. 无风险、成本与储备

- 首个执行日从开盘开始，`risk_free_return = 0`。
- 后续日期使用上一交易日已经可知的 DGS3MO `calendar_daily_factor`，按实际日历间隔乘方，
  与回测层储备仓位计息完全一致。
- 累计交易成本定义为 `sum(transaction_cost_amount)`，单位为初始 NAV=1 的财富单位，
  不与最终 gross-net 差额混称；该指标归入策略 `net` 口径。
- 模板 B 平均储备仓位为每日收盘 `RESERVE close_weight` 的算术均值。
- 模板 A 的平均储备仓位标记为 `not_applicable`，不以零值混淆经济含义。

## 6. 版本与存储

- `metric_versions` 固定方法配置、方法哈希、代码哈希、依赖锁哈希、Git 提交和 Python 版本。
- `factor_diagnostic_sets` 与 `factor_diagnostic_periods` 保存共享诊断汇总和逐期明细。
- `metric_publications` 保存每个 `run_id + metric_version` 的输入清单哈希、结果哈希和复用身份。
- `performance_metrics` 使用长表保存 series、gross/net、metric key、值、状态、原因、样本数和单位。
- 相同已发布指纹直接复用；新方法必须产生新 `metric_version`，不得覆盖旧结果。
- 诊断集和指标发布采用同事务 `publishing → published` 两阶段发布；发布后父子记录均禁止追加、修改或直接删除，
  仅允许在版本归档门禁通过后随上游父记录级联清理。
