# 因子回测引擎 v0.1：阶段 3 实施报告

日期：2026-07-31  
状态：通过

## 本阶段范围

阶段 3 只完成因子注册、日频因子值计算、版本化存储与质量验收。因子层不执行方向翻转、横截面排名、Top 2 选择、趋势过滤、仓位生成或绩效计算。

## 冻结因子池

共 11 个公式定义、24 个独立参数变体：

- 普通动量：20、60、120、252 日。
- 跳过近期动量：120-20、252-20。
- 短期反转：5、10 日。
- 均线趋势：20/60、60/120。
- 距离近期高点：60、120 日。
- 历史波动率：20、60 日。
- 下行波动率：20、60 日。
- 最大回撤：20、60、120 日。
- 风险调整动量：60、120 日。
- ATR 占比：14、20 日。
- 成交量趋势：20/60 日。

不同参数组合均为独立 `factor_variant_id`。原始因子值按定义保存，`higher_is_better` 或 `lower_is_better` 仅作为注册元数据，留待信号层统一处理。

## 公式补充口径

- 动量和反转的 N 日窗口需要 N+1 个价格观察值。
- 历史波动率使用 N 个复权收盘对数收益的样本标准差（`ddof=1`），乘以 `sqrt(252)` 年化。
- 下行波动率使用 `sqrt(252 × mean(min(log_return, 0)^2))`。
- 最大回撤使用包含当日的 N 个复权收盘价窗口，保存最大回撤绝对值。
- ATR 使用 Wilder 递推：首个 ATR 为 N 个 True Range 的算术平均，之后使用 `(前值 × (N-1) + 当日 TR) / N`。
- 成交量趋势使用供应商原始成交量，不使用价格复权因子调整。
- 任一公式在共同有效起点之后出现未定义、空值或非有限值时，因子数据集发布失败。

## 数据库新增对象

- `factor_definitions`：公式、字段、方向和实现标识。
- `factor_variants`：参数实例和最小有效观察数。
- `factor_values`：数据、清洗、因子、变体、资产和日期六维主键下的原始因子值。
- `factor_datasets`：已发布因子数据集的内容哈希、共同有效起点、截止日期和行数。

新增 Alembic 迁移 `20260731_0003`。因子值通过复合外键绑定到清洗行情；因子变体通过复合外键绑定到其因子版本，防止跨版本错配。
