# M7E1 实施报告

## 交付结果

M7E1 已建立实验定义与实际运行之间的边界。数据库 head 为 `20260804_23_v02_experiment`。

- `experiment.experiment_specification`：一个完整且不可变的原子实验请求；
- `experiment.experiment_suite`：一个有名称、版本和完整候选 manifest 的实验集合；
- `experiment.experiment_suite_cell`：Suite 内有序 cell 与可复用 Specification 的映射；
- Suite 仅保存调用方明确给出的 cells，不隐式生成模型、策略、成本、基准和区间的笛卡尔积；
- cell key 仅是 Suite 内展示身份，不改变原子规格 fingerprint；
- 相同 Specification 可被多个 Suite 复用；
- Specification 直接依赖 Strategy Target、Benchmark、Cost、Metric Catalog 和三个 Engine artifact；完整 Factor→Signal→Model→Strategy→Data 血缘由 manifest 自动展开；
- 当前只接受 `carry_in`，不把尚未实现的 fresh-start 伪装成可运行规格；
- Suite 的所有 Specification 与 Suite 自身在同一事务中发布，任何输入或引擎角色错误都会整体回滚；
- 数据库触发器再次校验已发布输入、engine key、simulation end，并冻结 published 记录。
