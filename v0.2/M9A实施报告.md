- 将中文品牌固定显示为“候鸟实验室”，英文显示为 “Migratory Bird Lab”；
- 为 12 个首批因子提供直观数学表达、中文含义和可折叠的精确计算定义；

- 保持 API、数据库、目录和不可变 artifact 中的英文 key 与精确公式不变。

## 2. 为什么不把公式当 Markdown

Factor Catalog 保存的是确定性计算定义，例如
`close_adj[t] / close_adj[t-window] - 1`。它不是 Markdown，也不是 LaTeX。
直接交给 Markdown 渲染器不会自动得到正确数学公式，还会模糊“展示公式”和“精确实现”的边界。

M9A 因此采用两层展示：

1. 默认显示适合阅读的数学记号和经济含义；
2. 展开后显示目录中的原始计算定义，用于审计和复现。

前端不解析或执行公式，也没有使用 `dangerouslySetInnerHTML`。

## 3. 内部标识符为什么仍然保留

完全隐藏 `factor_key`、`signal_key` 或 `metric_key` 会让截图更简洁，却会削弱研究追溯。
完全原样展示又会让中文页面像数据库浏览器。当前折中是：

- 人类可读名称是主要信息；
- 稳定英文 key 使用较小等宽字显示；
- 目录、API、血缘和内容哈希不因翻译而改变。

这使中文翻译可以继续优化，而不改变任何研究对象身份。

## 4. 双语边界

固定界面、正式经济解释和常用研究术语在 zh-CN/en 间切换。数据目录与运行审计中的自由文本仍以发布时的原文为准，避免前端翻译改变正式记录。后续如需完全本地化自由文本，应在发布协议中增加版本化的 message key，而不是根据字符串临时机器翻译。

## 5. 无障碍基线

- 页面提供跳过侧栏的主内容链接；
- 主导航和语言选择具有本地化可访问名称；
- 当前语言通过 `aria-pressed` 表达；
- loading、empty、error 使用状态或警报语义；
- 所有可交互控件具有明显的键盘焦点轮廓；
- 质量圆点仅作装饰，质量文字仍独立表达状态；
- 窄屏继续使用既有单列布局，长标识符允许安全换行。
