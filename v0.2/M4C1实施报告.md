# M4C1 实施报告：版本化 Forward Return Target

## 交付结果

M4C 拆为两个可独立验收的小阶段。本阶段完成评价标签地基；下一阶段 M4C2 才计算 Signal 诊断并接入 API/UI。

- 新增机器目录 `forward_returns.v0.2.0.json`，定义 weekly 与 monthly 两个并行 target；
- 新增严格契约和纯计算器，按 XNYS 共同交易日生成非重叠的下一开盘到下一调度开盘收益；
- 新增独立 Forward Return Engine，冻结代码、依赖锁、schema 和数值环境；
- 新增不可变 definition/version/dataset/value 表及 Alembic 迁移；
- dataset 显式绑定 universe、bundle、canonical market、calendar、engine 和请求/覆盖区间；
- 候选 ETF 与 SPY benchmark 均生成标签，最后一个不完整区间不发布；
- 新增 CLI、目录验收、计算单元测试和现有合成 E2E 接线。

## 精确语义

决策点为每个 ISO week 或 calendar month 的最后共同交易日收盘。收益起点为其下一共同交易日 `open_adj`，终点为下一次同频调度后的执行 `open_adj`。因此标签与未来策略的“收盘决策、下一开盘执行”语义一致，不会把决策日收盘到下一开盘的不可交易收益误归给信号。

标签只有在终点不晚于请求区间末日时才发布。缺失执行开盘、非正价格、重复交易日或重复价格均明确失败，不静默删掉资产或区间。
