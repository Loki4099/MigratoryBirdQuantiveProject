# M7E2 实施报告

## 交付结果

M7E2 已让 Atomic Experiment Specification 成为可执行、可审计的研究任务。数据库 head 为 `20260804_24_v02_exp_result`。

- 新增版本化 `experiment_orchestration_engine`；
- 新增不可变 `experiment.result_publication`，每个 Specification 最多一个 accepted Result；
- 执行顺序固定为 Benchmark Target → Strategy/Benchmark Gross → 同成本 Net → Interval Performance → Quality Checks → Accepted Result；
- 已发布中间产物按 fingerprint 自动复用，不重复复制计算结果；
- `ops.run_attempt` 记录运行引擎、Specification root、请求 fingerprint、attempt number、状态和时间；
- `run_artifact` 保存完整输入和每一步输出，`run_event` 保存有序过程事件；
- `quality_check_result` 检查输出发布状态、区间可用性和规格输入一致性；
- 历史不足的区间以 completed run、warning check 和 excluded accepted Result 保存；
- 执行异常形成 failed attempt、run_error 和失败事件，不产生 accepted Result；
- 再次执行已有 accepted Result 的 Specification 不新建 attempt，直接返回原结果；
- 数据库 acceptance trigger 独立复核 Run、Specification、Interval Result 和质量状态，应用服务不能绕过。
- 修正 M7C Benchmark Target 唯一约束遗漏 Benchmark Engine 版本的问题，避免未来引擎升级被旧业务键错误阻止。

## 验证

- Ruff：通过；
- strict Mypy：146 个源码文件通过；
- 单元测试：194 项通过；
- 真实 PostgreSQL 端到端覆盖 eligible acceptance、excluded warning acceptance、结果复用、执行失败审计和 published result 冻结；
- 完整 PostgreSQL 集成回归：19 项通过。
