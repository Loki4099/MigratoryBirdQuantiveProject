# M4C2A 应用端学习笔记：如何阅读 Signal 诊断

## 这些指标回答什么

- Rank IC：同一个决策日，Signal 排序和四只候选 ETF 后续收益排序是否一致；
- 正 IC 比例：可定义的观察中，有多少次方向为正；
- Top-Bottom：按 Signal 选出的前两名与后两名，后续平均收益相差多少；
- IC IR：Rank IC 均值相对其波动有多稳定，本项目按 weekly/monthly 频率年化；
- 事件率：交叉事件 Signal 在全部资产观察中实际触发的比例；
- 事件资产集中度：事件是否几乎只发生在少数资产上，第一版采用事件次数的资产 HHI；
- 非中性率：Signal 给出非零方向的频率；
- 潜在 Top-2 换手：相邻目标日期的前两名发生了多少变化，它是 Signal 行为诊断，不是含成本的策略换手；
- 成对诊断：两个 Signal 的分数、收益差路径或 Top-2 选择有多相似。

## 为什么不能只看一个高数字

系统只有四个候选 ETF，单期 Rank IC 的统计信息有限；短区间还可能偶然很好。因此页面以后必须同时展示有效期数、不可定义次数、年度窗口、目标频率和质量警告。`0.85` 相关阈值只是提示两个 Signal 可能重复，不代表其中一个错误。

## v0.2 的选择及取舍

统一共同样本提高横向可比性，但会放弃个别 Signal 独有的更长历史。年度窗口容易解释，数据少时却不够稳定；第一版先保留这种透明拆分，不引入复杂的自动显著性筛选。Signal 可以进入研究的硬条件仍是经济解释、完整规格、无未来信息、数据覆盖和技术验证，不要求先达到统一 IC 门槛。

## 如何检查实现

同一个 weekly 或 monthly evaluation 中，各 Signal 的 full-window period count 应一致。Rank IC 为空时必须有原因；事件率只应出现在事件 Signal；相关性超过阈值只能显示提醒，Signal 仍应存在。任意结果都应能追溯到 Signal Catalog、51 个 Signal Dataset、资产池、数据包、资格快照、Forward Return Dataset 及两个计算引擎。
