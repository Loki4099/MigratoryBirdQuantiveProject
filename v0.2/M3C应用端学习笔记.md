# M3C 应用端学习笔记

## 为什么诊断不直接写回 Factor Dataset

Factor Dataset 在发布后已经冻结。如果后续新增一种诊断就修改原数据集，旧研究结果的内容会被悄悄改变。独立 Diagnostic Set 的优点是原值保持不变、诊断算法可以单独升级、任何页面结果都有自己的血缘；代价是对象与版本数量更多。

## 分布指标能告诉我们什么

均值和中位数描述典型水平，标准差描述离散程度，P05–P95 描述大部分观测所在范围，最小值与最大值帮助发现边界。它们适合检查量纲、异常值和退化序列，但不能单独证明一个因子有预测力。

## Spearman 与普通相关性的选择

Spearman 比较排序关系，而不是要求两个数值呈严格线性关系。不同因子量纲可能完全不同，例如 RSI、收益率与 Amihud，因此排序相关性更适合第一轮冗余筛查。代价是它忽略具体数值距离，不能替代全部研究诊断。

## 为什么高相关不自动删除

高相关可能来自短样本、特定市场阶段或共同趋势，也可能是经济含义不同但当前数值相似。自动删除会把研究判断藏进系统规则。v0.2 只提醒，由研究者结合经济家族、参数、其他区间和后续增量价值决定。

## 参数稳定性应该怎样阅读

同一公式不同窗口高度相关，说明参数变化后测量排序大致稳定；低相关说明短中长期可能观察到不同现象。两者都不天然是好或坏，更不表示策略收益。页面必须同时显示 Universe、数据版本和共同区间，因为换一个上下文，结论可能变化。

## 审查类似方案时可以问

1. 诊断是否与原始数据分开版本化？
2. 被比较的序列是否使用完全相同的资产和日期？
3. 相关性是 Pearson、Spearman，还是其他口径？
4. 高相关阈值是提醒还是自动决策？
5. 参数稳定性是否只比较同一定义实例？
6. 页面有没有把预测方向或策略收益错误地塞进 Factor 层？
