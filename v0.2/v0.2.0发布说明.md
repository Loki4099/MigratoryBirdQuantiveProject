# v0.2.0 候选发布说明

状态：**尚未冻结。长历史 canonical 套件已完成，完整 Model/K 参数空间仍待分批物化。**

v0.2.0 是风格轮动研究平台的第一套完整重建基线。它不迁移或复现 v0.1 数据，而是在版本内执行严格的不可变发布、内容校验、血缘追溯和确定性重算原则。

## 已交付

- Asset/Universe/Data、Factor、Signal、Model、Strategy Product、Experiment Result 分层；
- 四只美国风格 ETF、SPY 产品基准与 DGS3MO 合成储备收益；
- 12 个因子定义、28 个参数变体、51 个信号和 86 个种子模型；
- 三类横截面 Top-K 策略语义、K=1/2/3、周/月频和下一交易日开盘执行；
- 2/5/10 bps 单边成本、carry-in 多区间绩效、SPY 主基准；
- 因子、信号、模型独立诊断；策略绩效只在 Experiment 中出现；
- accepted Result、严格 Comparison Cohort、单指标排名、受控 Compare 与 Decision Explorer；
- 中英文只读 React 界面、可访问性和研究术语可读性基线；
- 可恢复的 Strategy Grid 与正式 Experiment Suite 发布、真实 PostgreSQL 集成回归、custom dump 与隔离恢复测试。

## 当前研究边界

当前正式展示数据库包含 90 个长期 canonical 实验单元：一个五维等权模型、三种策略、K=2、周/月频、2/5/10 bps 与 full/trailing 10/5/3/1-year。全历史绩效从 2007 年开始，五个区间均 eligible。它用于确认长期会计和页面语义，不是全部已登记模型和 K 敏感性配置的研究结论。新闻、宏观、产业轮动、机器学习权重、动态择时、做空、杠杆、衍生品和实盘交易均不在 v0.2.0 范围。

## 后续版本

v0.2.1 从本版本冻结基线开始，逐页改善可读性、翻译、图表和交互，并可在有经济或文献依据时扩充信号及相应后端契约。任何改变正式结果语义的修改都生成新版本，不覆盖 v0.2.0 发布物。
