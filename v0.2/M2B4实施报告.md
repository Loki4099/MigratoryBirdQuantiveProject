# M2B4 实施报告：只读 Data API 与双语数据页面

## 交付结论

M2 已完成纵向闭环。系统现在可以通过一个只读、版本化的 API 投影已发布数据链，并在中英双语页面中展示源证据、规范/衍生数据集、覆盖率、质量问题、冻结数据包和逐资产可用性。前端不重算数据资格，也不混入任何策略绩效指标。

## 已交付

- `GET /api/v2/data/overview` 与 ETag 缓存契约；
- OpenAPI/Pydantic/TypeScript 三端同步类型；
- 仅查询 `published` artifact 的 PostgreSQL read model；
- 数据集级 `ok/warning/error` 和整条链路的 `partial` 状态；
- source、dataset coverage、quality issues、bundle members、eligibility items/issues 展示；
- React Data 页面、响应式布局与 zh-CN/en 文案；
- API 单元测试、真实 PostgreSQL 数据链集成测试和前端组件测试。

## 关键边界

API 只做读取投影，不执行清洗、资格计算或研究计算。缺少 dataset、bundle 或 eligibility 时返回 `partial/data.incomplete_chain`；存在 error issue 时返回 error；存在 warning 或不合格资产时返回 warning。页面忠实展示这些状态，不以空白或“正常”掩盖不完整链路。

Data overview 默认返回最近 50 个已发布源快照、全部已发布数据集、最新已发布 bundle 和最新已发布 eligibility snapshot。这里的 latest 只用于研究浏览界面；正式因子和实验仍必须绑定具体 artifact ID，不能把浏览查询当成计算输入选择器。
