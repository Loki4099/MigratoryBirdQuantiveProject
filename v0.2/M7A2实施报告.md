# M7A2 实施报告：Gross Portfolio Path

## 交付结果

M7A2 将 M7A1 的纯组合会计核心接入正式发布链。系统现在可以把已发布 Strategy Target Path 转换为版本化、不可变、可追溯的 Gross Portfolio Path；这一层不应用交易成本。

## 应用端理解

Target Path 回答“策略想持有什么”，Gross Path 回答“考虑下一交易日开盘执行、隔夜价格变化和储备收益后，组合在不计成本时实际如何演化”。两者分开后，2/5/10 bps 可以在下一阶段共享同一套目标和标准化交易记录，避免重复计算产生不一致。

Gross Path 明确固定 Target Path、Data Bundle、Execution Policy、Reserve Return Model 和 Accounting Engine。它保存每日 gross NAV、每日资产与 reserve 收盘权重、每次决策对应的执行日、交易前与目标权重、adjusted open 执行价，以及 one-way turnover 与 gross traded fraction。

## 主要约束

- 只接受已发布的 model Strategy Target Path 和 Accounting Engine；
- 执行政策必须来自生成该 Target Path 的 Strategy Product；
- Data Bundle 必须与 Target Path 完全一致；
- reserve model 必须可从 bundle 内 reserve dataset 的依赖关系追溯；
- 缺少共同交易日、adjusted OHLC 或 reserve interval 时正式发布失败；
- 父 artifact 发布后，gross 主表及全部子表均不可修改；
- gross path 不保存成本、净 NAV 或跨成本场景的美元成交额。

## 验证

- Ruff 与 strict Mypy 通过；
- 167 个单元测试通过；
- PostgreSQL foundation migration 回归 4 个测试通过；
- 端到端 PostgreSQL 研究链通过，包含发布幂等性、下一共同交易日执行、每日预算守恒和 artifact 不可变性。

下一阶段 M7B 将基于同一 Gross Path 建立 2/5/10 bps Net Cost Path。
